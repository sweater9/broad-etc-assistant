# Broad ETF Investment Assistant — V1

A static, GitHub Pages-ready prototype for ranking broad-based ETFs and deciding where to direct a monthly AED contribution.

## V1
- Broad-based-only universe
- Default target: 65% CSPX / 20% EIMI / 15% WSML
- Alternatives: SSAC and Vanguard FTSE All-World (VWRA/VWRP share class)
- Manual portfolio values
- Editable monthly AED contribution
- Transparent 0–100 scoring model
- Recommendation history (in-session)

## Run
Open `index.html`, or serve the directory with any static server. It can be deployed directly with GitHub Pages.

## Important
The valuation/trend/risk/macro inputs in V1 are demo inputs for validating the recommendation UX and logic. Do not treat them as live market data.

## V2
Replace demo signals with market/fund data; add persistent history; optional read-only IBKR portfolio integration. IBKR API market data can require subscriptions and authentication.
